# AiTraceRoot NFT Animation Assets

These files are looping animated SVG assets for the three ERC721 badges.

| Badge | File | Suggested Metadata Field |
|---|---|---|
| Pioneer Badge | `pioneer-badge.svg` | `animation_url` |
| Advocate Badge | `advocate-badge.svg` | `animation_url` |
| Builder Badge | `builder-badge.svg` | `animation_url` |

The assets contain no visible text and can be rendered as square NFT previews.
