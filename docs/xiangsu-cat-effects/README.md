# 像塑猫猫特效项目

## 项目目标

本项目只面向 **像塑特效平台** 落地，目标是制作一组低实现难度、强传播、适合宠物猫用户反复拍摄的原创猫猫特效。

## 参考原则

用户提供的现有像塑/抖音猫猫特效案例仅用于提炼底层机制，**不得复刻现有特效**。

可参考：
- 真实猫主体 + 强拟人/反差
- 猫脸/头部贴纸跟踪
- 简单 2D 道具绑定
- 随机结果
- 点击触发
- 序列帧/简单粒子
- 结果型文案
- 轻量小游戏 UI

禁止直接照搬：
- 已有职业、人设、世界观
- 已有发型/帽子/眼镜组合
- 已有“天使/恶魔”等主题
- 已有文案
- 已有完整互动流程
- 已有视觉构图的一比一复刻

## 像塑优先技术边界

第一阶段只使用像塑内可稳定实现的能力：

- 宠物/猫主体识别
- 头部或面部区域跟踪
- 2D 贴纸绑定
- UI 图层
- 点击触发
- 随机数/随机结果切换
- 简单序列帧
- 简单粒子
- 预制文字/结果图
- 基础音效和时间轴

第一阶段直接 PASS：
- 外部 AI 模型实时推理
- LivePortrait / SAM / MMPose 等作为运行时依赖
- 双猫复杂识别
- 精细身体骨骼
- 猫咪真实跳舞/弹琴等高难动作驱动
- AI 实时视频生成
- 复杂 3D
- 多主体复杂剧情
- 高成本嘴型/情绪实时识别

原则：**看起来聪明，实际上实现简单。**

# 第一批 6 个原创低难度方案

## 1. 猫咪电量检测

### 核心玩法
猫进入镜头后出现“正在检测猫咪剩余电量”，电池动画从低到高快速跳动，最后随机停在一个结果。

### 示例结果
- 3%：急需充电 / 充电方式：罐罐 × 1
- 23%：省电模式启动
- 66%：状态正常，可继续营业
- 100%：警告：精力过剩 / 今晚预计跑酷 7 次

### 像塑实现
宠物识别 → UI 显示 → 电量序列帧/进度动画 → 随机结果 → 对应文案素材切换。

### 难度
极低。

---

## 2. 猫咪 Wi‑Fi

### 核心玩法
猫头顶出现 Wi‑Fi 图标，模拟连接“猫猫网络”，最后随机显示连接状态。

### 示例结果
- 信号 100%：已连接主人
- 信号 1%：拒绝与人类通信
- 无网络：只接受罐罐通信
- 正在连接：CAT_5G
- 网络拥堵：正在处理摸摸请求

### 像塑实现
头部贴纸绑定 → Wi‑Fi 序列帧 → 随机结果 → 文案/UI 切换。

### 难度
极低。

---

## 3. 猫咪系统报错

### 核心玩法
猫进入镜头后弹出仿系统警告窗口，模拟系统发现一个“未知猫猫进程”。

### 示例文案
SYSTEM WARNING  
检测到未知猫咪进程

CPU：3%  
可爱占用：100%  
拆家风险：87%

最终：
程序无法关闭  
原因：猫拒绝退出

### 可选视觉按钮
[喂罐罐]  [继续运行]

第一版按钮只需要视觉表现，不要求复杂真实交互。

### 像塑实现
猫出现 → UI 弹窗 → 数值/扫描动画 → 随机结果 → 报错提示。

### 难度
极低。

---

## 4. 猫咪今日模式

### 核心玩法
猫进入镜头后显示“正在读取猫咪系统”，多个模式快速轮播，最终随机停在一个模式。

### 示例模式
- 睡眠模式
- 高冷模式
- 干饭模式
- 拆家模式
- 粘人模式
- 省电模式

### 示例结果
今日模式：拆家模式  
家具请自行保重。

### 像塑实现
UI → 快速文字/图片轮播 → 随机停止 → 结果卡片。

### 难度
极低。

---

## 5. 猫咪脑内加载中

### 核心玩法
猫头顶出现 Loading 圈和百分比，模拟猫正在思考，加载完成后显示荒谬的“脑内结果”。

### 示例过程
正在思考……
12% → 37% → 81% → 100%

### 示例结果
- 饭呢？
- 今晚几点跑酷？
- 为什么这个人一直拍我？
- 罐罐库存不足
- 今日不想营业

### 像塑实现
头顶 Loading 贴纸 → 数字序列帧 → 时间触发 → 随机结果切换。

### 难度
极低。

---

## 6. 猫咪隐藏属性扫描

### 核心玩法
扫描线从猫身上划过，屏幕出现 CAT SCAN UI，若干属性数字快速变化，最后生成一个随机隐藏属性。

### 示例属性
可爱：98  
脾气：73  
饭量：99  
拆家：42  
智商：加载失败

最终：
隐藏属性：家庭统治者

### 像塑实现
扫描线动画 → HUD/UI → 数字变化 → 随机结果 → 大章/结果卡。

### 难度
低。

# 第一批优先顺序

建议制作顺序：

1. 猫咪系统报错
2. 猫咪电量检测
3. 猫咪脑内加载中
4. 猫咪今日模式
5. 猫咪 Wi‑Fi
6. 猫咪隐藏属性扫描

原因：前三个最容易在像塑里先跑通，并且视觉辨识度高。

---

# 素材规范

每个特效优先准备：
- 透明 PNG 贴纸
- 9:16 竖屏 UI
- 不依赖字体实时渲染的关键结果文案图
- 序列帧素材尽量短
- 简洁音效：扫描、弹窗、完成、报错
- 所有素材原创，不使用用户提供案例中的现成元素

---

# 后续执行规则

每做一个特效都必须：

1. 先确认像塑现有节点/能力可以实现。
2. 不为了“更酷”引入外部复杂模型。
3. 第一版优先保证稳定、跟踪不飘、触发清楚。
4. 完成预览测试后再继续下一个。
5. 记录使用到的像塑节点、素材、参数和问题，方便后续复用成猫猫特效模板。
